# 🧮 Kalkulator Sederhana Java

Projek kalkulator berbasis konsol (CLI) yang dikembangkan menggunakan bahasa pemrograman Java untuk memenuhi tugas kelompok.

## 📌 Fitur Utama
*  **Operasi Aritmatika Dasar:** Penjumlahan, pengurangan, perkalian, dan pembagian.
*  **Penanganan Error:** Validasi input untuk mencegah error pembagian dengan angka nol.
*  **Antarmuka Konsol:** Tampilan berbasis teks yang simpel dan mudah digunakan.

## 🛠️ Persyaratan Sistem
* Java Development Kit (JDK) versi 8 atau yang lebih baru.
* VS Code / IDE Java lainnya.

## 🚀 Cara Menjalankan Projek
1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/PutroeZalfa/Tugas-Kalkulator-Kelompok7.git
   cd Tugas-Kalkulator-Kelompok7
   javac Kalkulator.java
   java Kalkulator
   ```
